# ⚡ Энергетик — приложение бегового клуба

Учёт годового пробега (заряд молнии до 1000 км), таблица клуба, календарь событий и
чат с эмодзи, реакциями, фото и голосовалками. Работает в браузере, ставится на
телефон как приложение. Данные общие для всех — на бесплатном Supabase.

---

## Что понадобится
- Аккаунт на **GitHub** (github.com) — бесплатно.
- Аккаунт на **Supabase** (supabase.com) — бесплатно.
- Ничего устанавливать на компьютер не нужно: сборка идёт на серверах GitHub.

---

## Шаг 1. База данных (Supabase) — ~5 минут
1. Зайди на supabase.com → **New project**. Придумай имя и пароль, регион выбери поближе.
2. Дождись создания проекта (~1–2 мин).
3. Слева открой **SQL Editor** → **New query**. Открой файл `supabase-schema.sql`
   из этого проекта, скопируй всё содержимое, вставь и нажми **Run**.
4. Открой **Project Settings → API** и скопируй два значения:
   - **Project URL** (вида `https://xxxx.supabase.co`)
   - **anon public** ключ (длинная строка).

## Шаг 2. Вставь ключи в приложение
Открой файл **`src/config.js`** и замени заглушки на свои значения:
```js
export const SUPABASE_URL = "https://xxxx.supabase.co";
export const SUPABASE_ANON_KEY = "тот-самый-anon-key";
export const ADMIN_PIN = "смени-на-свой";
```
> anon-ключ можно спокойно хранить в коде — он для этого и предназначен.

## Шаг 3. Залей на GitHub
1. На github.com нажми **New repository**, назови, например, `energetik`, сделай
   его **Public**, создай.
2. На странице пустого репозитория выбери **uploading an existing file** и перетащи
   туда **все файлы из этой папки** (включая скрытые `.github` и `.gitignore`).
   Либо, если знаком с git:
   ```bash
   git init && git add . && git commit -m "Энергетик"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/energetik.git
   git push -u origin main
   ```

## Шаг 4. Включи GitHub Pages
1. В репозитории: **Settings → Pages**.
2. В разделе **Build and deployment → Source** выбери **GitHub Actions**.
3. Открой вкладку **Actions** — там пойдёт сборка. Через 1–2 минуты она станет
   зелёной, и появится ссылка на приложение (вида
   `https://твой_логин.github.io/energetik/`).

## Шаг 5. Раздай клубу
- Кидай ссылку в общий чат клуба. Все, кто её открывают, видят один и тот же чат,
  таблицу пробега и календарь.
- На телефоне: **iPhone** — «Поделиться» → «На экран „Домой“»; **Android** —
  меню ⋮ → «Добавить на главный экран». Появится значок как у обычного приложения.
- Себе зайди в **Профиль → Режим администратора**, введи свой PIN — сможешь
  добавлять события в календарь и удалять сообщения.

---

## Обновить приложение потом
Меняешь любой файл на GitHub (кнопка ✏️) → коммитишь → сборка сама пересобирает
сайт за пару минут.

## Запуск на своём компьютере (необязательно)
Если установлен Node.js 18+:
```bash
npm install
npm run dev      # откроется localhost для разработки
npm run build    # готовая сборка в папке dist
```

## Заметки
- Логин/пароль не нужны — участник просто вводит имя и аватар. Личность хранится
  в браузере, поэтому таблица считает пробег по каждому устройству.
- Фото сжимаются на телефоне до ~1 МБ и хранятся в базе.
- Если захочешь закрыть вход по «коду клуба», аккаунты, пуш-уведомления или
  фото у пробежек — всё это добавляется поверх этой основы.
